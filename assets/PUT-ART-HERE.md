# Drop mascot / illustration art in this folder

Pasted images in chat can't be read from disk — save the file here and it can be
processed, background-removed, sized, and wired into the build.

Expected, as of Aug 2026:

| file | what it is | where it goes |
|---|---|---|
| `loop-monster.png` | the blue Loop mascot (waving, spark dashes overhead) | phone + desktop hero, empty states, the connect-your-classroom prompt |
| `bubbles.png` | purple + gold speech bubbles with spark dashes | the Tonight's Conversation tile |

Transparent PNG is ideal. A white-background PNG is fine — the white gets keyed
out on import.
